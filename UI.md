## 4. Keep/Try 테이블 (Reflect)

```
😊 Keep - 오늘 효과 있었던 것들

┌──────────────────────────────────────────┐
│  내용                    │ 언제 떠올릴까?  │
├──────────────────────────────────────────┤
│  아침이 집중 잘됨         │ [시작 전 ▼]    │
│  SNS 알림 끄기           │ [작업 중 ▼]    │
└──────────────────────────────────────────┘
   ↑ 메모를 여기로 드래그하면 Keep으로 저장돼요


🔄 Try - 다음에 시도해볼 것들

┌──────────────────────────────────────────┐
│  내용                    │ 언제 떠올릴까?  │
├──────────────────────────────────────────┤
│  비행기 모드 켜기         │ [시작 전 ▼]    │
└──────────────────────────────────────────┘
   ↑ 메모를 여기로 드래그하면 Try로 저장돼요
```

## 5. 목표 시각화

### Leverage 체크
```
과제 순서를 정해주세요
드래그해서 바꿀 수 있어요!

①  ☐ 개요가 md 형태로 작성됨
②  ☐ 3개 섹션 초안 완성됨

─────────────────────────────────

시작 전에 이것만 체크해요 ✓

   ☐ 비행기 모드 켜기
   ☐ 물병 책상에 두기

     다 체크하면 시각화가 시작돼요
```

### 시각화 진행
```
              ◯ 24

   블로그 포스트 초안 완성하기

        ① 개요가 md 형태로 작성됨
        ② 3개 섹션 초안 완성됨
```

### 시각화 완료
```
              ✓

   블로그 포스트 초안 완성하기

         준비됐어요!

              시작 ▶
```
